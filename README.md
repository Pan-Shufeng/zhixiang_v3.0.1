# 知向 zhixiang_v3.0.1

知向是一个面向商业信息探索的联网判断助手。它把自然语言问题转成可追踪的搜索计划，帮助用户寻找公开来源、读取原文、比较证据并保存判断。

## 两种使用方式

- **独立网页应用**：Windows 用户运行 `启动知向联网版.cmd`，浏览器打开 `http://127.0.0.1:8186`。
- **MCP 工具**：先运行网页服务，再将 `MCP配置示例.json` 中的路径配置到支持 MCP 的 AI 客户端。工具入口是 `zhixiang_search`。

## 开源运行

本仓库不包含任何 API Key、个人数据或运行日志。第一次使用时，在应用设置中填写自己的兼容模型 API；公开搜索默认使用 Bing RSS，也可以配置自己的 Tavily Key。联网搜索和模型分析都需要网络。

Windows 体验包可以从 Releases 下载；也可以按 `packaging/build_package.py` 自行构建。体验包只提供运行环境，不替代阅读源码。

## 目录

- `backend/`：Python 后端、搜索适配器、MCP 适配器
- `frontend/`：前端源码和构建入口
- `packaging/`：Windows 便携包构建脚本
- `API_CONTRACT.md`：HTTP 接口说明
- `使用说明.md`：用户操作与边界
- `MCP配置示例.json`：客户端连接示例

搜索摘要只是线索；来源是否可靠、原文是否完整仍需用户核对。
